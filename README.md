# স্বাধীন স্পর্শ — সম্পূর্ণ ফ্রি ব্যাকএন্ড (Render + PostgreSQL)

## এই সেটআপে কী আছে
- Node.js/Express সার্ভার (ChatGPT ছবি এডিটিং + প্রিন্ট ম্যানেজার API)
- PostgreSQL ডেটাবেজ (Render-এর ফ্রি টিয়ার, কোনো কার্ড লাগে না)
- ফ্রন্টএন্ড (ওয়েলকাম পেজ, ফটো এডিটর, প্রিন্ট ম্যানেজার) একই সার্ভার থেকে সরাসরি চলবে

## মোট খরচ: ৳০ / মাস
কোথাও কোনো কার্ড লাগবে না — না Render-এ, না Postgres-এ।

## একমাত্র ট্রেড-অফ যা মেনে নিতে হবে
১৫ মিনিট নিষ্ক্রিয় থাকলে সার্ভার "ঘুমিয়ে" যায় — পরের ভিজিটে সাইট খুলতে
৩০-৬০ সেকেন্ড সময় লাগে। এটা ফ্রি টিয়ারের স্বাভাবিক আচরণ, কোনো ত্রুটি না।

## গুরুত্বপূর্ণ: প্রতি ৩০ দিনে একটা ছোট কাজ করতে হবে
Render-এর ফ্রি PostgreSQL ৩০ দিন পর মেয়াদ শেষ হয়ে যায় (তারপর ১৪ দিনের
গ্রেস পিরিয়ড)। মেয়াদ শেষ হওয়ার আগেই নতুন একটা ফ্রি Postgres বানিয়ে
সংযুক্ত করে দিতে হবে — খুব বেশি সময় লাগে না (৫ মিনিটের কাজ), এবং
প্রতিবার আমি ধাপে ধাপে সাহায্য করব। ক্যালেন্ডারে একটা রিমাইন্ডার
সেট করে রাখতে পারেন যাতে ভুলে না যান।

## লোকাল কম্পিউটারে টেস্ট
এই সেটআপে ডেটাবেজ অংশ (প্রিন্ট ম্যানেজারের রেট/হিস্ট্রি) লোকাল
কম্পিউটারে কাজ করবে না, যেহেতু লোকালি কোনো Postgres নেই। এটা
স্বাভাবিক — শুধু `npm install` করে দেখুন কোনো এরর ছাড়া ইনস্টল হয়
কিনা, বাকি আসল টেস্ট Render-এ ডিপ্লয়ের পর হবে (গাইডে বিস্তারিত)।

## ফাইল গঠন
```
server.js          → মূল ব্যাকএন্ড সার্ভার
package.json        → প্রয়োজনীয় লাইব্রেরির তালিকা
.env.example         → এনভায়রনমেন্ট ভ্যারিয়েবলের নমুনা
public/
  index.html          → ওয়েলকাম পেজ + হোম ড্যাশবোর্ড
  photo-editor-module.html
  print-manager-module.html
```

## ChatGPT (OpenAI ইমেজ মডেল) — ঐচ্ছিক
OPENAI_API_KEY না দিলেও কোনো সমস্যা নেই — বিল্ট-ইন ফ্রি ফটো এডিটর
(রঙ-ভিত্তিক স্মার্ট সিলেকশন) সবসময় কাজ করবে। ChatGPT-এর ইমেজ মডেল
পরে যেকোনো সময় চালু করা যাবে — platform.openai.com থেকে key নিয়ে
.env-এ বসালেই হবে (নতুন অ্যাকাউন্টে সাধারণত $5 ফ্রি ক্রেডিট থাকে,
কার্ড ছাড়াই সাইন-আপ করা যায়; এরপর প্রতি ছবিতে সামান্য খরচ হয়)।
